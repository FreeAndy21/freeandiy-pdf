# FreeANDIY PDF app icon

The angel Andy (Free Andy Agency) on the FreeANDIY PDF colour, with the `Pd` monogram. At 32 px
and below the angel is unreadable, so those sizes show the lowercase monogram `pd` instead.

These files are **generated**: do not edit them here. The source is
`tools/make_icons.py` in the FreeANDIY meta repository (colours in `freeandiy/branding.toml`), and
`freeandiy/scripts/regenerate.sh` copies the output from `freeandiy/assets/icons/pdf/`.

| File | Use |
|---|---|
| `freeandiy-pdf.svg`, `freeandiy-pdf-small.svg` | vector master (trace) |
| `freeandiy-pdf-1024.png` | macOS window/Dock icon, on Apple's 824/1024 grid |
| `freeandiy-pdf.icns` | macOS bundle icon |
| `freeandiy-pdf.ico` | Windows icon, 16–256 px, embedded in the `.exe` |
| `freeandiy-pdf-mark.png` | app bar and About mark (monogram tile) |
| `hicolor/<size>/apps/agency.freeandy.pdf.png`, `hicolor/scalable/...svg` | Linux icon theme, window icon |
