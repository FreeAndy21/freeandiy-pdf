FreeANDIY PDF portable mode

While this file sits next to freeandiy-pdf.exe, FreeANDIY PDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the FreeANDIY PDF Data folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move FreeANDIY PDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\FreeANDIY PDF and
%LOCALAPPDATA%\FreeANDIY PDF) instead. If FreeANDIY PDF Data can't be written (for example on a read-only
drive), FreeANDIY PDF says so and uses the per-user folders instead.
